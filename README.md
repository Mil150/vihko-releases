# Vihko releases

Vihko — a personal Windows app that shows my own timetable and homework. Works with Wilma; not affiliated with Visma or any school. Releases here are for personal use, provided as is, without support.

Vihko — особистий застосунок для Windows, що показує мій власний розклад і домашні завдання. Працює з Wilma; не пов'язаний із Visma чи будь-якою школою. Релізи тут — для особистого користування, як є, без підтримки.

SHA-256 і підпис — у файлах `*.sha256`, `*.manifest.*` кожного релізу.
